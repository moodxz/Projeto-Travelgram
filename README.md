# 🌍 Travelgram

O **Travelgram** é uma interface de rede social inspirada no conceito de compartilhamento de viagens. O projeto simula um perfil de viajante, com destaque para fotos, localização, destinos visitados e número de países explorados.

✨ O foco é oferecer uma experiência visualmente agradável e imersiva para quem ama viajar.

## 🔍 Funcionalidades

- Perfil personalizado com nome, bio e localização
- Galeria de fotos em grade
- Ícones temáticos com uso de emojis e imagens
- Organização clara e clean, priorizando a navegação visual
